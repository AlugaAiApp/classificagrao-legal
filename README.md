# Classifica Grão — páginas legais

Site estático (GitHub Pages) com as páginas públicas exigidas pelo Google Play Console
para o aplicativo **Classifica Grão**:

| Página | Arquivo | Uso no Play Console |
|---|---|---|
| Política de Privacidade | `index.html` | URL da Política de Privacidade |
| Exclusão de conta e dados | `excluir-conta.html` | URL de exclusão de conta / de alguns dados |

O conteúdo é o mesmo servido pelo backend em `/politica-de-privacidade`
(`classifica_grao_server/resources/views/legal/privacidade.blade.php`). Ao alterar a
política lá, atualize aqui também.
